# Panduan Singkat Pengguna L-Note Laundry

Panduan ini untuk pemilik/operator laundry.

## 1. Login

1. Buka aplikasi L-Note.
2. Isi email dan password.
3. Tekan `Masuk`.

Jika gagal, cek koneksi internet atau hubungi admin.

## 2. Tambah Transaksi

1. Tekan `Tambah Transaksi`.
2. Pilih pelanggan.
3. Pilih layanan.
4. Isi berat cucian, contoh `1,5`.
5. Pilih:
   - `Hitung Sistem` jika harga mengikuti harga per kg.
   - `Harga Manual` jika ingin isi total sendiri.
6. Tekan `Simpan Transaksi`.

## 3. Tandai Lunas

1. Buka `Riwayat`.
2. Tekan transaksi yang ingin dilihat.
3. Tekan `Tandai Lunas` jika pembayaran sudah diterima.

Jangan tandai lunas kalau uang belum diterima.

## 4. Tambah Pelanggan

1. Buka `Pengaturan`.
2. Tekan `Data Pelanggan`.
3. Tekan `Tambah Pelanggan`.
4. Isi nama dan nomor HP.
5. Tekan `Simpan`.

## 5. Tambah Layanan

1. Buka `Pengaturan`.
2. Tekan `Data Layanan`.
3. Tekan `Tambah Layanan`.
4. Isi nama layanan dan harga per kg.
5. Tekan `Simpan`.

## 6. Lihat Laporan

1. Buka `Laporan`.
2. Lihat total transaksi, pemasukan lunas, dan belum lunas.
3. Ubah tanggal jika ingin melihat periode tertentu.

## 7. Backup Data

Backup dilakukan oleh admin/server. Jika ingin update aplikasi atau pindah server, minta admin melakukan backup terlebih dahulu.
